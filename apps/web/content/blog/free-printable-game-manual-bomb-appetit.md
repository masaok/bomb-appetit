The free printable game manual for Bomb Appétit is the manual web page itself. Open it, press the print button in its sidebar, and your browser's print dialog does the rest. There is no download, account or fee. Print rule seed 1 unless the bomb uses another number, then match the paper to the bomb.

## Where does the free printable game manual come from?

The printable manual comes from the same page the Experts read on screen. Each manual lives at an address that ends in its rule seed, so the standard one is at `/manual/1`. There is no separate PDF file to find. Whatever the page shows is what the printer gets, minus the sidebar.

A rule seed is the number that generates every rule in the manual. The address carries that number, which means any seed from 1 to 999,999 has its own manual page. Seed 1 is built ahead of time as the standard manual. Any other seed is generated the first time someone opens it.

Because the paper copy and the screen copy are the same page, nothing gets out of date between them. A group can print [the standard manual](/manual/1) and know the sheets match what a teammate sees on a phone, as long as both use the same seed.

The game costs nothing to play and needs no account, so the manual is free in the same way. Signing in only adds leaderboards and saved progress. Printing needs nothing but a browser and a printer.

## Printing the manual from the browser

To print the manual, open it, press the button labelled "Print or save as PDF" in the sidebar, and pick a printer or a PDF in your browser's dialog. The button calls the browser's own print command. The page is laid out for black and white paper, with each section starting on a new sheet.

What the print layout does:

- **It drops the screen tools.** The sidebar with the module filter, the seed box and the print button does not appear on paper.
- **It starts each section on its own page.** The opening page, every module, the edgework appendix and the glossary each begin on a fresh sheet.
- **It switches to black text on white.** The page colors are replaced with white backgrounds and black text and lines.
- **It names every color in words.** Where a rule mentions a color, the color name is written out next to a small swatch, so a grey printout still reads correctly.

Here is the full run from screen to paper, as a step list:

1. Open the manual page for your seed. For the standard rules, that is `/manual/1`.
2. Look at the top of the opening section. It reads "manual 1 (standard)" for seed 1, or the seed number on its own for any other.
3. Press "Print or save as PDF" in the sidebar.
4. In the browser's print dialog, choose your printer, or choose to save as PDF if you want to print later or share the file.
5. Print the whole document. Every module and needy module gets a page, plus the opening page, the edgework appendix and the glossary.
6. Collect the stack and check that the sections run from the opening page through to the glossary.
7. Check the seed. Compare the number on the opening page with the manual number the bomb uses, and write it on the front of the stack.

Once the stack is printed, the next job is handing it out. The guide to [dividing the printed pages between Experts](/blog/print-and-play-games-one-screen-stack-of-pages#dividing-the-printed-pages-between-experts) shows example splits for two, three and four Experts.

## Which rule seed should you print?

Print rule seed 1 for almost every game. It is the standard manual, freeplay starts on it, and nineteen of the twenty missions use it. Print a different seed only when the bomb you will play uses that number, such as the final mission or a freeplay bomb set to another seed.

The seed to print follows the bomb, not the other way round. A few cases:

- **Missions.** Each mission on the [missions page](/missions) lists the manual it needs. The final mission, called Bomb Appétit, uses manual 2026, so it needs its own printout.
- **Freeplay.** The freeplay setup has a field labelled "Manual (rule seed)". If someone changed it from 1, print the matching number.
- **A fresh challenge.** A group that knows seed 1 too well can pick any other number. Open that manual with the seed box in the manual's sidebar, then print it.

Every page of a printed manual is tied to its seed. The manual's own glossary puts it this way: a bomb only works with the manual that has its rule seed.

## The printing mistake: a manual for yesterday's seed

The common printing mistake is reaching for a stack printed for an earlier game. Different seeds produce different rules, yet the pages look alike, with the same module names and the same layout. Before every round, compare the seed printed on the paper with the bomb's manual number, and reprint if they differ.

This mistake is easy to make because a printed manual feels permanent. It sits in a drawer and gets reused. That is fine while the group keeps playing seed 1. It goes wrong the night someone tries the final mission, or plays a freeplay bomb on another seed, and then the old stack comes back out the following week.

A few habits prevent it:

- Write the seed in large digits on the front sheet of every stack.
- Keep stacks for different seeds in separate folders, labelled with the number.
- Say the seed aloud before the timer starts, and have each Expert confirm the number on their pages.
- When in doubt, open the manual for the bomb's seed on a phone and compare the opening page with the paper.

The opening page of every manual asks for the same check. It tells the Expert which manual number they are holding and warns that a different number means different rules. Treat that paragraph as part of the setup, not as text to skip.
